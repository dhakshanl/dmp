## Install

1. Click **Download / Update**.
2. Unzip `MissionPlanner-latest.zip` anywhere, for example `C:\NavXDrone`.
3. Run `MissionPlanner.exe`. No installer needed.

## Update

The app checks for a new release every time it starts and offers to update itself.

To update by hand, click **Download / Update** and unzip over your existing folder, choosing *Replace* when asked. Your settings are kept, because they are stored in `Documents\Mission Planner`, not in the app folder.

## Windows warning

The build isn't code-signed, so Windows may show *"Windows protected your PC"*. Click **More info → Run anyway**.

On PCs with **Smart App Control** turned on, Windows blocks the app completely. Run it in Windows Sandbox or on another PC instead.
